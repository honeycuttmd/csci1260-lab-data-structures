**Name:** Madison Honeycutt
**Section:** 002
**Language:** C#

## About this Lab

This lab demonstrates the implementation of common data structures, including arrays, generic lists, stacks, queues, dictionaries, and hash tables. It also uses LINQ to filter, sort, group, and summarize course data. The program runs eight sections (Parts A-H) and displays the results in the console.

## How to run

Open the DataStructuresLab project in Visual Studio and run the program, or navigate to the project directory in a terminal and use:

```
dotnet run
```

The application runs all eight parts and prints their results to the console.
